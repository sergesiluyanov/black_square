# Black Square

Мессенджер со сквозным шифрованием и поддержкой пересылки файлов. Создан на Flutter.

## Возможности

- **Сквозное шифрование (E2E)** — все сообщения и файлы шифруются на устройстве с помощью AES-256
- **Пересылка файлов** — отправка любых файлов с шифрованием
- **Локальное хранение** — данные хранятся локально в зашифрованном виде

## Технологии

- **Flutter** — кроссплатформенная разработка
- **AES-256-CBC** — шифрование сообщений и файлов
- **Flutter Secure Storage** — защищённое хранение ключей
- **Hive** — локальная база данных
- **Provider** — управление состоянием

## Запуск

```bash
flutter pub get
flutter run
```

Доступные платформы: iOS, Android, macOS, Windows, Linux, Web.

## Структура проекта

```
lib/
├── main.dart              # Точка входа
├── models/
│   ├── chat.dart          # Модель чата
│   └── message.dart       # Модель сообщения
├── screens/
│   ├── chat_list_screen.dart   # Список чатов
│   ├── chat_screen.dart       # Экран чата
│   └── new_chat_screen.dart   # Создание чата
└── services/
    ├── chat_service.dart     # Логика чатов и шифрования
    ├── encryption_service.dart  # E2E шифрование
    └── storage_service.dart   # Локальное хранилище
```

## Безопасность

- Ключ шифрования генерируется при первом запуске и хранится в защищённом хранилище (Keychain/Keystore)
- Сервер не имеет доступа к расшифрованным сообщениям
- Файлы шифруются перед сохранением
